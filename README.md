# 📡 Radar de Oportunidades & Repositórios (GitHub API)

Projeto desenvolvido em Python para automação de coleta e análise de dados de repositórios do GitHub utilizando a API REST oficial.

## 🎯 Objetivo
Buscar automaticamente os projetos mais recentes sobre tecnologias específicas (como Python, Data Science, etc.), extrair informações estratégicas e exportar um relatório estruturado em formato `.csv`[cite: 8].

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **Requests** (Consumo de API REST e tratamento de requisições HTTP)
* **Pandas** (Estruturação e manipulação de DataFrames)

## 🚀 Como Executar
1. Clone o repositório ou descarregue os arquivos.
2. Instale as dependências necessárias no terminal:
   ```bash
   pip install requests pandas
